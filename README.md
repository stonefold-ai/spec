# Legacy Stonefold schemas and fixtures

This repository retains machine-readable schemas, examples and fixtures used by the earlier gateway implementation. The previous prose specification collection has been retired. These artifacts are historical implementation inputs, not the architecture or backlog for a new application.

Documentation cleanup does not change schema semantics or certify the implementation. Consult the consuming code and tests when reproducing previous behavior.

[Security reporting](SECURITY.md) and [contribution instructions](CONTRIBUTING.md) remain available. Runtime or schema changes require their own review.
